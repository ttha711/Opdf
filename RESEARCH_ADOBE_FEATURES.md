## PART 6: ⚡ Offline vs Online — Tổng kết

| Loại | Số tools | Chi tiết |
|------|----------|----------|
| **Offline hoàn toàn** (WASM/Node) | ~25+ | pdf-lib, pdfjs, qpdf-wasm, tesseract.js, fabric.js, node-signpdf, diff-pdf, fflate |
| **Offline partial** (cần bundle binary) | ~5 | pandoc (binary), docling (model), Stirling-PDF (Java), ocrmypdf (Python), verapdf (Java) |
| **Online** (cần cloud API) | ~3 | Cloud storage, request signatures (Adobe Sign), shared review (Acrobat Cloud) |
| **Chưa có opensource giải pháp tốt** | ~8 | Edit text in-place (HummusJS partial), XFA forms (deprecated), Create form UI, 3D annotations, geospatial PDF, rich media, JavaScript in PDF, imposition tools |

> **Kết luận:** Với pdf-lib + pdfjs + qpdf-wasm + tesseract.js + fabric.js + node-signpdf, có thể đạt ~60-70% chức năng Adobe Acrobat **hoàn toàn offline**, chạy trong Electron. Phần còn lại chủ yếu là chuyên ngành hẹp (in ấn, GIS, 3D, collaboration cloud).
